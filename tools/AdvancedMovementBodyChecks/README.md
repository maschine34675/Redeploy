# Advanced Movement outgoing-body checks

Runs the production optional adapter and Core ownership context against boundary doubles,
using the installation's real Harmony library. The fixture mirrors Advanced Movement 1.0.1's
private state layout; no upstream implementation or assets are bundled.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/AdvancedMovementBodyChecks/Verify.ps1 -PublishedDll <AdvancedMovement.dll>
```

The checks exercise read-only preparation, refused/failed preparation, base and derived world
unregister hooks, a living Slide and Dive, residual state after native death, repeated replacement,
same-profile but physically different bodies, late unregister callbacks, independently rebound
resources, unrelated movement overrides, failed cleanup, optional absence and an older contract.
The four mutation controls must fail their named ownership/lifecycle assertions. `NativeCompile`
compiles the actual adapter against installed EFT assemblies without any deployment target.

`-PublishedDll` also checks the real release's complete reflected field/method surface, physical
animator ownership and move-state speed restoration IL. Reports and its SHA-256 go below
`artifacts/advanced-movement-body-checks/`; `-EvidenceRoot` overrides the evidence parent.
This is not an in-game movement test. Native acceptance must start real upstream Slide/Dive
states and verify the outgoing state and new body's input after the actual Core pipeline.
