## Defect and boundary

DERP's private static `_localPlayer` caches the first non-destroyed player. A
retained outgoing body therefore keeps authorizing optics and resolution changes
after a Core respawn. Its optic/aim callbacks also evaluate `CurrentScope` before
testing whether the animation has scopes. EFT indexes `ScopeAimTransforms` in
that getter, so a replacement's empty hands or knife can throw.

Core binds the optional plugin once per instance/version. The native hooks and
their signatures are rechecked at replacement preparation. Repeated menu admission
does not resolve reflection members or walk Harmony patches. An absent plugin has
no patches to remove. Newer plugin versions may bind matching APIs with one warning.

The adapter changes only Core-owned physical replacements. During creation the
foreign getter returns no player. After the game and world commit the exact new
body, Core updates the private cache without waiting for another optic event.
Failed preparation does not mutate the cache or retire the current weapon. An
own-Scav continuation follows physical ownership, independent of profile ID.

Successfully retired physical gun/optic callbacks cannot alter the new camera.
Only the outgoing body and held-gun hierarchies are inspected, once per replacement.
Weak tombstones do not retain corpses. A pooled optic genuinely mounted on the
current player's gun is admitted again. Unrelated bot callbacks retain the foreign
mod's behavior. Empty-scope callbacks are guarded only in the owned raid, while a
current optic's disable callback can still restore normal resolution.

At world retirement Core clears only its exact owned cache. It does not change
graphics settings, resampling algorithms, SSAA/DLSS/FSR values or global camera
state. A subsequent ordinary raid uses DERP's original behavior. The initial
ordinary player and pre-Core upstream issues are outside this adapter's authority.

## Verification

`tools/DynamicExternalResolutionChecks` links the production adapter/context and
uses real Harmony with a small native/foreign fixture. Its 29 assertions cover
creation, cancellation, consecutive respawns, own-Scav identity, empty hands,
detached/retired optics, unrelated bot callbacks, pooled reuse, exact retirement,
the next ordinary raid and missing upstream hooks. Five negative controls removing
the cache handoff, retired-callback fence, empty-scope, negative-index and null-scope
guards each failed their specific assertion or reproduced the expected indexing
exception. The original baseline passed again afterwards.

Scoped native checks passed on SPT-GPU-1 on 13 November 2026. The frozen Core
1.0.23 candidate has SHA-256
`6E4F0BA1D32CACFE584F11C367E97A7957BE1F001142FB422770C712CC7C8696`
and loaded/disk MVID `c66effad-400f-4697-8788-e94d777750e2`. It was built from
the working source committed as `54093c9`; its informational commit stamp is
the preceding `8c6cd87`, not the later source commit.

Factory Team Deathmatch exercised magnified ADS on the initial Arena body and
after an actual death. In both cases DERP changed applied DLSS input dimensions
from 1114 x 627 (ratio 0.580208361, quality 1) to 640 x 360 (ratio 0.333333343,
quality 3), then restored the former values when ADS ended. Knife lean after
replacement did not produce a scope exception. The complete protected profile
comparison differed only in the Hideout bookkeeping timestamp.

A separate process loaded Redeploy.Client with ArenaMode absent. PMC-to-own-Scav
continuation produced a new physical body and DERP's cache matched that exact
body. The first attempted Scav ADS measurement was inconclusive: the scoped rifle
was present in equipment, but drawn hands and active optic ADS were not recorded.
A bounded repeat explicitly drew the SR-25, confirmed `IsAiming` and
`CurrentScope.IsOptic`, and saved two stable 640 x 360 readings ten seconds apart.
ADS exit restored 1114 x 627. No new gameplay errors were recorded; the host's
existing microphone initialization error was unrelated.

This is bounded Factory/DLSS evidence, not coverage of every graphics mode or
third-party combination. Friendly-marker alignment, a renderer-menu reset, and
retired-optic callback races were not separately demonstrated in game; ownership
and delayed-callback cases remain covered by the offline harness. Evidence is in
the sibling ArenaMode four-mod worktree's ignored
`artifacts/four-mods-20261113/` and its dated GPU report. No foreign DLL is shipped.

Public source and release payload are stored only in ignored
`../ArenaMode/artifacts/compat-fourmods-20261113/derp/`. The third-party DLL is not
